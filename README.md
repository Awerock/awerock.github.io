# Sleepwalking — After Hours

Редизайн сайта команды на основе ветки `dev`: ночная палитра, орбита, шлейф курсора, адаптивные карточки игроков, фильтры дисциплин и окно профиля. Реальные фотографии, имена и ники перенесены из прежнего сайта.

## Запуск и редактирование

Нужен Node.js 22 или новее. Установка пакетов не требуется.

1. Дважды нажмите **start-editor.cmd** в папке проекта.
2. Откройте http://127.0.0.1:4173/admin/ — панель владельца.
3. Нажмите **Добавить игрока**, заполните имя, ник и игры. Можно загрузить фотографию JPG, PNG или WebP до 5 МБ и добавить описание.
4. Нажмите **Сохранить игрока**. Для существующих карточек доступны **Изменить** и **Удалить**; удаление требует подтверждения.
5. Проверьте результат по ссылке **Посмотреть сайт** или http://127.0.0.1:4173/src/.

Не закрывайте окно запуска, пока пользуетесь редактором. Если браузер открылся раньше сервера, обновите страницу через несколько секунд. Если порт занят, завершите предыдущий запуск. Обычное открытие `index.html` как файла не поддерживает загрузку состава — используйте локальный сервер.

## Что сохраняется

Состав записывается в `src/data/players.json`, новые фотографии — в `src/img/uploads/`. Это реальные файлы, изменения сохраняются после закрытия браузера и перезапуска компьютера. Перед каждым изменением состава сервер создаёт копию предыдущего JSON в `.backups/` (не публикуется).

Кнопка **Скачать копию состава** сохраняет JSON отдельно. Для восстановления: остановите редактор, скопируйте нужный JSON из `.backups/` вместо `src/data/players.json`, затем запустите редактор. Фотографии при удалении игрока не удаляются, чтобы резервные копии оставались пригодными для восстановления.

Если состав изменили в другом окне, сервер откажется перезаписывать более новую версию: обновите страницу и повторите правку.

## Публикация в GitHub Pages

Сохранение в редакторе **не обновляет публичный сайт автоматически**.

1. Запустите **publish.cmd**.
2. Просмотрите список изменений и подтвердите отправку словом `YES`.
3. При необходимости авторизуйтесь в GitHub через обычный механизм Git. Для первого коммита должны быть настроены имя и почта Git.
4. Скрипт создаст коммит файлов сайта и редактора и отправит ветку `dev` в `Awerock/awerock.github.io`.
5. Дождитесь успешного развёртывания GitHub Pages. В настройках репозитория источник публикации должен соответствовать этой ветке; настройки публикации этим проектом автоматически не меняются.

Скрипт не выполняет принудительную отправку. Если GitHub содержит новые изменения, отправка остановится: нужно сначала согласовать версии. Локальные файлы останутся на месте. Успешный `git push` сам по себе не подтверждает успешное развёртывание Pages.

## Доступ к панели

Редактор предназначен для владельца на этом компьютере: сервер слушает только `127.0.0.1`, проверяет адрес, источник запросов и временный токен сеанса. На публичном GitHub Pages редактор не запускается и изменить состав через него посетители не смогут. Пароли и GitHub-токены в браузер и файлы сайта не добавляются.

Это локальная панель, а не облачная админка: для управления с телефона или другого компьютера понадобится отдельное решение с авторизацией и общим серверным хранилищем.

## Дизайн и причины решений

Полный брендбук и исходные обоснования — в **[DESIGN.md](DESIGN.md)**.

- Ночной фон и лавандовый свет развивают прежнюю космическую тему и название Sleepwalking.
- Первый экран сразу предлагает познакомиться с командой; вступление вынесено в отдельный заметный блок.
- Крупная типографика и короткие тексты заменяют длинные растянутые абзацы.
- Единая обработка реальных портретов объединяет состав. При наведении фотографии возвращаются к цвету.
- Орбита нарисована средствами CSS: без тяжёлого видео или стороннего 3D-движка.
- Тонкий шлейф использует ограниченное число точек и затухает примерно за 380 мс. Обычный курсор сохраняется.
- На сенсорных устройствах шлейф отключён. При системном уменьшении движения декоративные анимации отключаются; в подвале есть ручной выключатель эффектов.
- В реализации использованы уже имеющиеся локальные Museo Sans Cyrl и Roboto. Они не требуют запросов к внешнему сервису шрифтов. Golos Text / Roboto Condensed из концепции остаются кандидатами для дальнейшей настройки.
- Вместо формы с неустановленным способом доставки заявок используется существующая ссылка Discord. Актуальность приглашения нужно подтвердить владельцу; новые заявки не имитируются.
- Факты о составе взяты из прежнего сайта. Выдуманных достижений и статистики нет.

## Структура

Логотип команды из предоставленного владельцем PNG сохранён без изменения рисунка и цвета в `src/img/team-logo.png`. Он размещён в блоке вступления и подвале. Режим смешивания `screen` позволяет чёрному фону изображения сливаться с ночным фоном страницы; сам исходный файл не редактировался.

### Земля, Луна и карточки

В шапке оставлено только название Sleepwalking. Композиция Земли и Луны целиком помещается в первый экран без обрезания орбиты. Материки — стилизованная векторная карта, а не точная географическая модель; Земля поворачивается за 160 секунд, Луна проходит орбиту за 64 секунды и скрывается за Землёй на дальней стороне.

Звёзды разделены на три слоя глубины и смещаются с разной скоростью при прокрутке. При отсутствии прокрутки они не требуют постоянной перерисовки. Орбита останавливается за пределами видимой области и в неактивной вкладке.

Карточки игроков наклоняются вслед за указателем примерно до 5 градусов, получают мягкий блик и подсвеченную рамку. Наклон применяется ко всей карточке, чтобы она ощущалась единым предметом. На сенсорных экранах, при уменьшении движения и ручном отключении эффектов наклона нет. Новые карточки редактора получают эффекты автоматически.

Новые визуальные стили находятся в `src/css/cosmos.css`, карта — в `src/img/earth-map.svg`. Скрипт публикации включает эти файлы.

| Путь | Назначение |
| --- | --- |
| `src/index.html` | Публичная страница |
| `src/css/afterhours.css` | Дизайн и адаптивность |
| `src/js/afterhours.js` | Состав, фильтры, профили, шлейф |
| `src/data/players.json` | Общие данные игроков |
| `editor/` | Локальный сервер и панель владельца |
| `start-editor.cmd` | Запуск в Windows |
| `publish.cmd` | Подтверждаемая отправка в GitHub |

Старые Sass/Gulp-файлы сохранены для истории и не участвуют в новом интерфейсе. Для текущей версии сборка не требуется. Публичная страница работает как статический сайт на GitHub Pages.

Земля плавно увеличивается при прокрутке до 115% и уменьшается при возврате вверх. Движение Луны переведено с обновления координат разметки на translate3d; вращение поверхности Земли также использует transform. При отключении эффектов масштаб возвращается к 100%.
