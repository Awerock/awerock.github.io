Твоя команда.

Добавляй игроков, меняй фотографии и управляй составом.

Сохранение обновляет файлы на этом компьютере. Чтобы изменения увидели посетители, опубликуй их в GitHub.

Загружаем состав…

Перед каждым сохранением автоматически создаётся резервная копия состава.

Игрок

Удалить игрока?

Карточка исчезнет из состава. Резервная копия останется на компьютере.

Публикация

1. Сохрани изменения и проверь сайт по ссылке «Посмотреть сайт».

2. В папке проекта запусти publish.cmd. Он покажет изменения и попросит подтвердить отправку.

3. При необходимости войди в свой GitHub. После успешной отправки дождись обновления GitHub Pages.

Редактор доступен только на этом компьютере. Пароли и токены в сайт не добавляются.
